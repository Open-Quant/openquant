# Data sources

This file records every market data source that openquant ships, uses or has considered, with each
source's terms. It exists because of issue #43 and hypothesis H2 in
[the production-readiness brief](docs/design/production-readiness-brief.md) (RQ-011, owner decision 3).

**Rule.** The repository commits only data whose terms allow redistribution. Data fetched through
`openquant.data.fetch` from a user's own source is cached on that user's machine (by default
`~/.cache/openquant/data`, outside the repository) and is never committed.

## Fetch-only adapters (user-supplied)

`openquant.data.fetch` takes any `DataSource`: an object with a `name` and a `fetch_symbol(symbol, start, end)`
method. Wrap your own function in `CallableSource`. The adapter calls **your** account with **your** key. Read
the key from an environment variable inside your function, never from the repository. **Your use is governed
by your agreement with that vendor.** Pass the vendor's terms URL as `terms=` so that it is recorded in the
cache sidecar and in the run manifest.

openquant ships **no** vendor-specific network adapter. The owner has not chosen a vendor, and the terms below
show that most vendors restrict even local caching on some plans.

## Candidates for a real redistributable sample (owner decision)

The owner's decision on #43 (2026-09-19) says that no real data is committed until the candidates have been
researched, recorded here and brought to the owner. **Nothing below has been committed.** These are the only
candidates found whose primary terms appear to allow redistribution:

1. **Quandl WIKI Prices** (community-maintained US equities, daily, frozen around 2018-03). Quandl's dataset
   page, read through a Wayback Machine capture of 2016-02-20
   (https://web.archive.org/web/20160220230521/https://www.quandl.com/data/WIKI), declared the data public
   domain, free to copy and redistribute. Caveats: the grant is on an archived page and not on a live one; the
   data is crowdsourced, has known quality gaps and stops in 2018; and a sample would have to be taken from
   archived CSV captures. Before choosing it, confirm that the grant still stands, for example with Nasdaq Data
   Link.
2. **IEX HIST** (IEX exchange TOPS/DEEP pcap files). https://www.iex.io/legal/hist-data-terms §01 allows
   distribution if the data carries IEX's prescribed attribution text and a link to the terms. IEX keeps
   ownership (§03), and the page does not address derived data. Caveats: these are IEX-only prints, not the
   consolidated tape, so volume is IEX volume only; daily bars have to be built from pcap files; and whether
   bars derived from the files are covered is not stated.
3. **Keep the SYNTHETIC sample** (the current state). It has no terms risk and is fully reproducible, but it is
   not real data, and the real-data runbooks (hypothesis H1) would still need each user's own adapter.

Rejected: Zenodo record 20192822 (CC BY 4.0) says it was pulled from Yahoo through yfinance, and a CC BY label
cannot override Yahoo's terms. Other datasets were also rejected when their licence label was not backed by
the terms of the underlying source.

## Changing this file

When you add a source, a sample or a fixture that contains market data, add a row with the URL of the terms
page you actually read, the date, and what the terms say about fetching and redistribution. If you could not
read the terms, write "unverified". Do not commit data whose row does not say that redistribution is allowed.
