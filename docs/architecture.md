# Architecture

Owner: repository maintainers. Update this when deployment boundaries, module responsibilities, or public interfaces change.

## Deployment
Start with the simplest deployable application that satisfies requirements. Record runtime, storage, external dependencies, and operational ownership before splitting services.

## Modules
Name each module, its responsibility, and the dependency direction. Keep dependencies explicit.

## Interfaces
Document stable inputs, outputs, failure behavior, and compatibility constraints. Link accepted decisions under decisions/.
