# SYNTHETIC sample data - not market data

`synthetic_daily_ohlcv.csv` is generated by `scripts/data/make_synthetic_sample.py`
from a seeded random process. The symbols `SYN_A` ... `SYN_E` are not real tickers
and the prices do not describe any real instrument. It is shipped so CI, the docs
and the runbooks run offline; it is read by `openquant.data.LocalSampleSource`.

It has no third-party terms and is covered by the repository's MIT license. See
`DATA_SOURCES.md` at the repository root for every data source and its terms.
Do not replace it with fetched market data.
